# Digital IC Design | Verilog HDL

Welcome to my Digital IC Design learning repository.

This repository documents my journey in Digital Design using Verilog HDL, RTL development, and digital circuit verification through simulation.

## Goals

- Build a strong foundation in Digital Logic Design.
- Learn Verilog HDL and RTL coding practices.
- Develop testbenches to verify digital designs.
- Simulate and debug designs using ModelSim.
- Practice professional Git and GitHub workflows.
- Document projects, test results, and lessons learned.

## Tools & Technologies

- **HDL:** Verilog
- **Simulation:** ModelSim
- **Version Control:** Git
- **Repository Hosting:** GitHub

## Project Workflow

Each project will follow a consistent workflow:

1. Define design requirements and expected behavior.
2. Implement the RTL using Verilog.
3. Develop a testbench.
4. Compile and simulate using ModelSim.
5. Analyze waveforms and debug issues.
6. Document verified results and design decisions.
7. Commit and push changes using Git.

## Projects

Projects will be added as they are developed and verified.

Each project will include its design files, testbench, instructions, and relevant simulation evidence when applicable.
